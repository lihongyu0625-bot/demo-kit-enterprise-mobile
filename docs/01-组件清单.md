# 组件清单

这份清单的目标只有一个：以后不管是继续做新页面，还是把组件上传到云端，都先看这张表。

## 当前测试页面

- 页面名称：酒店填单页
- 页面入口：`src/pages/HotelFormPreviewPage.jsx`
- 组件文件：`src/components/hotel-form/HotelFormComponents.jsx`
- 样式文件：`src/components/hotel-form/hotel-form.css`
- 页面规格：`src/page-specs/hotel-form.json`
- 模拟数据：`src/mock-data/hotel-form.mock.json`

## 建议的云端组件分层

为了后面上传云端更顺，建议分三层：

1. 基础层  
   放 `Checkbox`、`ToggleSwitch`、`PriceDisplay`、`FieldRow`、`CardShell`
2. 业务层  
   放 `HotelRoomInfoCard`、`HotelStayInfoCard`、`HotelBenefitCard`
3. 页面层  
   放 `HotelFormPreviewPage` 这种负责“组装页面”的文件

## 这张清单怎么维护

每新增一个组件，都补下面这 5 项：

1. 组件名
2. 中文用途
3. 主要入参
4. 复用范围
5. 是否适合上传云端
